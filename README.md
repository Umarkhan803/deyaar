# Deyaar Constructions (`deyaar`)

Offline construction management app for Deyaar Constructions (Flutter + sqflite).

## Features

- Dashboard, projects, clients, expenses
- Labour (workers, attendance, wages)
- Materials stock
- Payments (advance / receipt) with due reminders
- Reports + PDF export
- PIN lock
- **Site photos:** camera, **multi-select from gallery**, and short video — per project

## Run

```bash
cd "d:/Umar khan/reactnative/deyaar"
flutter pub get
flutter run
```

## Build APK

```bash
flutter build apk --release
```

Output: `build/app/outputs/flutter-apk/app-release.apk`
